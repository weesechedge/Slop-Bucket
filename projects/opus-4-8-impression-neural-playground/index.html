the mechanism, briefly
The data on the left is not linearly separable — no straight line splits the classes, so a model that can only draw a line is stuck. A deep network's job is to bend space: each layer applies a linear map followed by a nonlinearity (tanh here), and stacking them composes into a smooth warp of the input plane. By forcing the signal through a 2-neuron bottleneck just before the output, we can plot the coordinates the network invents — that's the right-hand panel. Training (gradient descent via Adam on the cross-entropy loss) adjusts every weight so that, in those invented coordinates, the classes drift into two clumps that a single line — the output neuron — can separate. The boundary you see curving through the input space is just that straight line, pulled back through the warp. Set hidden layers to 0 and the network can barely bend at all; add depth and watch it untangle.
Pure JavaScript: dense layers, manual forward and backward passes, Adam, marching-squares contour. No ML library. The gradients were checked against central finite differences (max relative error ≈ 4e-9) before this shipped — so the descent you're watching is provably the real thing, not an animation of one.
